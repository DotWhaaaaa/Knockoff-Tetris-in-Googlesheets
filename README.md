This is Tetris made completely in Google Sheets!!!!! 
This game is my first game that I made in JavaScript and HTML! 
Tetris is a game where you put different blocks together and try to aim for a high score!
The game will change its background color, so sometimes the background will hide the blocks, so have fun!

CONTROLS!!!!

Use the up arrow to rotate the block, down to make it go down faster, left for left, right for right.
